# Statistics for Machine Learning Resources

## Knowledge

- [Book: _An Introduction to Statistical Learning (ISLR)_ — James, Witten, Hastie & Tibshirani](https://www.statlearning.com)
  Foundational textbook for statistics in Machine Learning. Use for: linear regression, classification metrics, resampling methods (Bootstrap, CV), and regularization.
- [Book: _Reproducible Machine Learning for Credit Card Fraud Detection_ — Le Borgne, Sibroni & Bontempi (2021)](https://juleskeepshare.github.io/reproducible-ml-fraud-detection/)
  Practical handbook for imbalanced datasets and temporal validations. Use for: AUPRC, Cost-Sensitive learning, and temporal splits.
- [Documentation: _optbinning Python Library_](https://gnresende.github.io/optbinning/)
  Use for: Optimal binning, Weight of Evidence (WoE), and Information Value (IV) scorecard calculations.
- [Documentation: _Evidently AI_](https://docs.evidentlyai.com)
  Use for: Population Stability Index (PSI), Characteristic Stability Index (CSI), and Data Drift checks.
