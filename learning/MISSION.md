# Mission: Statistics for Machine Learning

## Why
Bridge the gap between generalist data science and the rigorous statistical requirements of specialized machine learning roles (like credit scoring, fraud modeling, A/B testing, and model drift analysis) to ensure mathematical metrics and algorithms make intuitive and operational sense.

## Success looks like
- Mathematically calculating and interpreting risk metrics: Weight of Evidence (WoE), Information Value (IV), and Population Stability Index (PSI).
- Applying resampling methods (like Bootstrap) and non-parametric tests to heavy-tailed transaccional distributions.
- Designing A/B testing frameworks that avoid selection biases (using Intention-to-Treat principles).
- Deploying and monitoring machine learning model drift using mathematical checks (KS statistic, PSI, Anderson-Darling).

## Constraints
- Guided by intuitive analogies and Python/SQL examples.
- Focus on practical application over abstract measure-theoretic proofs.
- Self-paced, structured, incremental lessons.

## Out of scope
- Advanced multivariable calculus proofs (excluding chain rule for backpropagation).
- Deep learning neural network architectures (except where statistical principles overlap).
- Abstract measure-theoretic probability.
